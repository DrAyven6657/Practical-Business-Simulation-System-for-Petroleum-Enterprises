# 石油企业经营实战模拟系统

本项目根据《石油企业经营实战模拟课程要求》制作，用 Python 标准库实现，不依赖 Flask、Django 等第三方 Web 框架。系统用于模拟石油企业在多个季度中的采购、生产、销售、库存和财务经营过程。

## 运行方法

```powershell
python app.py
```



本地必须装有python才可运行！



启动后打开：

```text
http://127.0.0.1:8000
```

## 主要功能

- 原油采购管理：录入季度采购量，系统按市场价格计算采购成本。
- 炼化生产计划：录入计划加工量，系统受产能、原油库存和成品率约束自动计算实际产量。
- 成品油销售管理：录入销售单价和推广费用，系统按需求函数计算销量。
- 库存管理：自动维护原油库存和成品油库存。
- 财务核算：自动计算收入、采购成本、生产成本、仓储成本、期间费用、利润和现金余额。
- 经营分析报表：展示 KPI、经营记录、利润趋势、库存趋势和文字化经营建议。

## 系统架构

一个 Python 文件，三层结构，零第三方依赖：

| 层 | 用什么 | 干什么 |
|----|--------|--------|
| 前端 | HTML + CSS + JS（全嵌在 `HTML` 字符串里） | KPI 看板、决策表单、历史表格、趋势图、业务模块 |
| 后端 | `http.server`（标准库） | 3 个 API：返回页面、查状态、提交决策 |
| 数据 | SQLite（标准库） | 两张表：`decisions`（输入）→ `results`（输出） |

核心逻辑就是一个函数 `simulate_decision()`：输入 7 个决策变量（采购量、加工量、售价、成品率、推广费、管理费、备注）→ 跑一遍 采购→加工→销售→成本→利润 的流水 → 输出完整季报。

```
输入：决策数据 + 历史状态
  │
  ├── 1. 原油采购 → 更新原油库存
  ├── 2. 计划加工 → min(计划量, 可用原油, 产能上限) = 实际加工
  ├── 3. 成品率折算 → 实际加工 × 成品率 = 成品油产出
  ├── 4. 需求函数 → f(售价, 推广费, 季节) = 市场需求
  ├── 5. 销量确定 → min(可售库存, 市场需求)
  ├── 6. 成本汇总 → 采购 + 加工 + 仓储 + 推广 + 管理
  └── 7. 利润现金 → 收入 - 成本 = 利润 → 现金滚动
  │
输出：本季度完整结果
```

特点：**零依赖、单文件**。拷走就能用，`python app.py` 即启动。

## 文件说明

- `app.py`：系统主程序，包含数据库、接口、页面和模拟算法。
- `oil_enterprise.db`：运行后自动生成的 SQLite 数据库。
- `docs/系统设计说明.md`：课程提交用系统设计说明，含设计思路、流程图、模块图和数据字典。

## 初始经营参数

- 初始现金：5,000,000 元
- 初始原油库存：2,000 吨
- 初始成品油库存：1,000 吨
- 单期产能：8,500 吨
- 成品率：默认 88%，每期可在决策面板调整（50%–99%）
